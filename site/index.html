常见问题FAQ

为什么不是满 1M？Why not the full 1M?

Codex 给每个模型设了上限（目前 Sol 是 872K），界面上还会留出约 5% 的余量，所以显示约 828K。这已经是 Codex 里能拿到的最大值。以后 OpenAI 放宽上限，再让 AI 调一次就行。Codex caps each model (872K for Sol today) and keeps about 5% in reserve, so you see about 828K. That's the most Codex allows. If OpenAI raises the cap, just ask your AI to run it again.

ChatGPT 网页版能用吗？Does it work for ChatGPT on the web?

不能。它只对 Codex 生效，包括桌面 App、命令行和编辑器插件。No. It only affects Codex: the desktop app, CLI and editor extensions.

会更耗额度吗？Does it use more quota?

要看你在 Codex 里是怎么登录的。以下都来自 OpenAI 官方文档：It depends on how you sign in to Codex. From OpenAI's official docs:

  • 用 ChatGPT 账号登录（订阅额度）：官方明确说明，GPT-6.1 Sol 在 Codex 里使用订阅额度时不收长上下文附加费。但每条消息消耗多少额度，和上下文长度有关：对话越长、带的内容越多，每条消息用得就越多，额度会消耗得更快。
  • Signed in with ChatGPT (subscription): OpenAI says GPT-6.1 Sol usage drawn from your subscription has no long-context surcharge in Codex. But how much each message uses depends on context length: longer conversations use significantly more per message, so your limit runs down faster.
  • 用 API Key 登录：按 API 价格计费。单次输入超过 272K tokens 时，整次请求的输入和缓存按 2 倍、输出按 1.5 倍计价。以 GPT-6.1 Sol 为例，每百万 tokens 的输入从 $2 涨到 $4，缓存输入从 $0.10 涨到 $0.20，输出从 $10 涨到 $15。
  • Signed in with an API key: you pay API prices. When a request has more than 272K input tokens, the whole request is billed at 2× for input and cache and 1.5× for output. For GPT-6.1 Sol, per 1M tokens: input $2 → $4, cached input $0.10 → $0.20, output $10 → $15.

上下文调大以后，只有对话真的变长才会多用。平时用不到这么长的话，随时可以让 AI 恢复默认值。A bigger window only costs more when conversations actually get that long, and you can ask your AI to restore the default at any time.

官方资料：Sources: Codex Pricing · GPT-6.1 Sol · API Pricing

重启后没变化？No change after restarting?

确认 Codex 是完全退出后再打开的（Windows 上记得看一下右下角托盘），并且是在新对话里查看。旧对话会保持原来的大小。Make sure Codex fully quit before reopening (check the system tray on Windows) and look at a new conversation. Old ones keep their size.
