常见问题FAQ

    

      

        为什么不是满 1M？Why not the full 1M?
        
Codex 会把设置限制在模型自身的上限内（目前 Sol 是 872K），界面上再扣掉约 5% 的预留，所以显示约 828K。想用满 1M 只能直接调用 API。以后 OpenAI 提高上限，重新运行一次就能拿到新的上限。Codex caps the setting at the model's own maximum (872K for Sol today) and shows about 95% of it, so you see about 828K. The full 1M is only available through the API. If OpenAI raises the cap, just run the command again.

      

      

        对 ChatGPT 网页版有用吗？Does it work for ChatGPT on the web?
        
没用。它只对 Codex 生效（桌面 App、CLI、IDE 插件）。ChatGPT 网页版和手机 App 没有本地设置可以改。No. It only affects Codex (desktop app, CLI, IDE extensions). ChatGPT on the web and mobile has no local setting for this.

      

      

        会更耗额度吗？Does it use more quota?
        
会。上下文越长，每次请求发送的内容越多，消耗的额度也越多。走 API 的话，输入超过 272K 后单价更高。Yes. A longer context sends more tokens with every request. On the API, input above 272K tokens is billed at a higher rate.

      

      

        重启后数字没变？Nothing changed after restarting?
        
确认 Codex 真的完全退出了（Windows 上检查系统托盘），并且是在新对话里看的。再检查一下有没有用某个 profile 或 -c model_context_window=... 覆盖了这个值。Make sure Codex fully quit (check the system tray on Windows) and that you're looking at a new conversation. Also check that a profile or a -c model_context_window=... flag isn't overriding it.

      

      

        直接运行网上的脚本安全吗？Is it safe to run a script from the web?
        
脚本完全开源，不到 200 行，只读写 ~/.codex/config.toml，不联网也不上传任何东西。不放心的话可以先在 GitHub 上看源码，或者下载下来先加 --dry-run 预览。The script is open source and under 200 lines. It only touches ~/.codex/config.toml and never goes online. Read it on GitHub first, or download it and run with --dry-run.
